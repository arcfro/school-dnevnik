Разработать цифровую платформу для школы: 
- электронный дневникжурнал с базовым функционалом (расписание, оценки, домашние задания и тд.) 
- PWA
- Интегрированные функциями отправки уведомлений в мессенджеры.
- связь с CRM
- для интерфейса используй UI UX Pro Max

Требования для портфолио:
Изображения формата JPEG, JPG, PNG, GIF, WEBP. Вес не более 10 МБ. Рекомендуемый размер 1920x1280 и более.
Видео формата MP4, AVI, MOV. Вес не более 50 Мб, длительность до 75 сек. Для горизонтальных видео размер не менее 660 х 165 px, для вертикальных видео размер не менее 132 х 440 px.
